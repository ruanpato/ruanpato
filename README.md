### Ruan Pato

**Hands-on Tech Lead · Software & AI Architect**

I design and deliver enterprise systems end to end: distributed backends, cloud platforms on AWS
and Azure, and AI applications that run in production. I own the architecture, lead the team that
delivers it, and stay hands-on in the implementation.

Currently Tech Lead / Specialist Software Engineer (GenAI) at Dataside, on a conversational-AI
program for a market leader in a regulated industry. I provide technical leadership for two
squads of software, AI and QA engineers and data scientists, working with content specialists,
product managers and product owners, and I own the architecture of the engagements I work on.
Recent work there: a shared retrieval platform for conversational assistants, a conversational
channel taken through security review and penetration testing into production, and a
distributed ML platform designed for a projected ~200 million new records per month.

#### What I work on

- **Architecture and distributed systems** — solution and software architecture, event-driven
  design, queues and asynchronous workflows, concurrency and distributed state.
- **Cloud and infrastructure** — AWS (Lambda, EKS, Aurora/pgvector, S3, SQS) and Azure (AKS,
  Service Bus, Key Vault, AI Search, Azure OpenAI), Kubernetes, Terraform, CI/CD and
  observability with OpenTelemetry.
- **AI applications in production** — retrieval-augmented generation with hybrid retrieval and
  reranking, MCP servers, agents with tool calling and human approval gates, evaluation and the
  data engineering behind it, tracing, and cost and latency control.
- **Security and identity** — Microsoft Entra ID (delegated authorization, on-behalf-of flow,
  Managed Identity), least privilege, private networking, and taking systems through security
  review and penetration testing into production.
- **Technical leadership** — architecture decisions, direct work with clients and architecture
  committees, and helping engineers grow from mid-level to senior.

Day to day: TypeScript/NestJS · Node.js · Python · PostgreSQL/pgvector · AWS · Azure ·
Kubernetes · OpenTelemetry · RAG · MCP · AI agents · LLM evaluation.

#### Open work

Most of what I build professionally lives in private client repositories. This is where I write,
teach and build in the open:

- [**AI Engineering in Production**](https://ruanpato.com/production-ai-engineering/en/) — an open
  handbook, in English and Portuguese, on designing, operating and governing AI systems in
  production: retrieval, agents, security, observability, cost and deployment. Open draft.
  [Source](https://github.com/ruanpato/production-ai-engineering) ·
  [Português](https://ruanpato.com/production-ai-engineering/)
- [**Study group**](https://github.com/ackermann-inverse/grupo-de-estudos) — material and runnable
  proofs of concept from sessions I prepared and presented for a small engineering study group:
  Azure Service Bus messaging, concurrency versus parallelism (Go, Node.js, Python), context
  engineering, and RAG engineering (hybrid retrieval, reranking, an evaluation harness and
  tracing). In Portuguese.
- [**TraceQuota**](https://github.com/ruanpato/tracequota) — local-first observability for AI coding
  agents: token usage, API-equivalent cost and quota, built on OpenTelemetry, PostgreSQL, Grafana
  and Phoenix. Early: verified end to end with synthetic workloads; native client sessions are not
  validated yet.
- [**TableDossier**](https://github.com/ruanpato/tabledossier) — portable data profiling: generate a
  notebook offline, run it where the data lives, and render a data dictionary, a quality report
  and an ER diagram from the exported profile. Alpha: tested on local Spark 3.5 and 4.0; not yet
  validated on a Databricks workspace.

Also: a bilingual [cybersecurity study handbook](https://ruanpato.com/cybersecurity-study-handbook/)
(beta), the [template](https://github.com/ruanpato/handbook-template) both handbooks are built on,
and the material from a [Git and GitHub workshop](https://github.com/ruanpato/oficina-git) I ran in
2021 (in Portuguese).
